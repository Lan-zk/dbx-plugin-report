二、需要你确认的五个点

  1. 保存触点在哪儿：顶部工具条单一“另存为”，每次都是另存为、不写回原文件。（代价：每次保存要弹框选路径）
  2. 截断怎么说：结果区顶部常驻“这是样本 500/5000”，并禁用总计与占比入口。（代价：常见问题“为什么总数不对”）
  3. 看板刷新怎么说：不给“截至 10:32”，只给逐卡时间；失败卡保留旧数据并标“旧”。（代价：页面看起来“脏”）
  4. 看板编辑入口：右上角“编辑布局”切换模式，而不是所有手柄常驻。（代价：多一次点击）
  5. 过滤器放哪儿：看板顶部一行，只作用于已取回行，并显式标注样本范围。（代价：不能做真正的服务端过滤）

三、统一约定

  • 颜色、圆角、字体只用宿主 token，不硬编码，装进 DBX 后视觉不变
  • 正文 13px / 控件 28px / 表格行 30px，桌面工具密度
  • “完整 / 最新 / 已保存 / 总计”四个词，没有依据就不出现
  • 每个失败都要给一个出口：重试、改设置、或明确说“只能这样”
  • 页面上所有带虚线橙色边的区域 = 原型说明，不属于产品界面

四、已知限制

!
多序列图表在暗色下不够用 宿主 --color-chart-* 是灰阶（212/115/82/64/38），暗色背景 rgb(19 20 22) 上第 4、5 档几乎看不见。原型只用 chart-3 / chart-2 / chart-1 三档，多序列色板需要在 M1 定稿前单独确认。
!
字体不是宿主那套 Geist 插件 iframe 是 opaque origin、CSP 不允许外链，拿不到宿主字体文件。原型按回退栈（PingFang SC / 微软雅黑）演示；若要一致，需要把字体打进插件包，代价是体积。
i
