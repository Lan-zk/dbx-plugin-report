## 2. 对 dbx-plugin-report 的结论

1. **能做的是“本地、作者驱动、只读”的报表闭环**，不是上述产品的服务端能力集合。宿主限制（无 bind/取消/分页/资产 API/调度/共享）决定首版只能做小闭环。
2. **可借鉴的结构**：查询与呈现分离（Evidence/Metabase）、报表/看板两级（Metabase/Superset）、指标字段契约（Cube/WrenAI 的“语义”概念）、逐卡状态与显式刷新（Rill）。
3. **不可移植**：语义编译器、Text2SQL 服务、权限/多租户、调度/订阅、打印引擎、拖拽式自由探索。这些都需要后端/宿主 API，且超出首版边界。
4. **AI 只做草稿**：所有项目的自动生成都依赖评估、语义层或人工复核；本插件没有资产审批/版本事务，AI 必须人工确认。
5. **图表库独立于这些项目**：优先 ECharts 或轻量 SVG；不要为了“像 BI”引入 Vega-Lite/完整可视化语法，除非 M0 证明必要。

## 3. 使用规则

- 星数/功能只作背景，不作需求；需求来自目标用户与宿主能力。
- 引用竞品结论时固定 commit/tag；本文快照不含 commit，正式引用需补。
- 不复制代码/配置/资产；结构借鉴需在 ADR 中写理由。
