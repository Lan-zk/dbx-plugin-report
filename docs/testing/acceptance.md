# 验收门与签收记录

> 用法：每个里程碑结束，逐项勾选、写证据链接、签名；未通过项必须写阻断原因与下一步。  
> 与 [roadmap.md](../development/roadmap.md) 的退出条件、[test-strategy.md](test-strategy.md) 的 V1–V8 对应。

## M0 验收（walking skeleton）

| # | 检查 | 通过标准 | 证据 |
|---|---|---|---|
| M0-1 | 真机安装 | `.dbxp` 在 DBX ≥0.6.51 安装成功，tab 可打开 | 截图/日志 |
| M0-2 | 权限/授权 | `queryData` 首次弹授权；拒绝可恢复；撤销后再次询问 | 录屏/错误码 |
| M0-3 | 数据查询 | 固定 SQL 返回正确 columns/rows/truncated/elapsedMs；连接未打开有明确错误 | 响应样例（脱敏） |
| M0-4 | 图表渲染 | 原生图表在 iframe 内显示；无 eval/worker 依赖；记录包体积 | 截图/构建报告 |
| M0-5 | 保存 | `saveFile` 弹对话框；取消返回 null；保存文件可解析 | 文件/日志 |
| M0-6 | 重开 | 拖入/打开 JSON → 校验 → 重新绑连接 → 重新执行 → 渲染 | 录屏 |
| M0-7 | 安全 | 无外部网络请求；无 `unsafe-eval`；日志无敏感值 | 抓包/代码审查 |
| M0-8 | 体验 | 查询/渲染不阻塞 UI >1s；错误可读 | 计时 |

**Go/No-Go**：全部通过 → M1；任一阻断 → 记录阻断点，不进入 M1。

## M1 验收（单报表竖切）

| # | 检查 | 通过标准 |
|---|---|---|
| M1-1 | 文档 v0 | schema/示例/校验规则落地；未知 major 拒绝；5 MiB 限制 |
| M1-2 | 数据集 | 固定 SQL、单连接、maxRows≤5000、运行/刷新、stale 检测 |
| M1-3 | 报表 | 表格+柱状、字段映射、单位/口径说明、作者确认版本 |
| M1-4 | 保存/重开 | round-trip 内容一致（允许 savedAt/revision 变化）；换机重映射；取消不置已保存 |
| M1-5 | 截断/错误 | A01–A16 通过；`truncated` 不得标完整；错误分类完整 |
| M1-6 | CSV | 当前结果导出：含时间/查询版本/范围/截断标记；公式注入转义 |
| M1-7 | 用户演练 | 2 名目标作者独立完成 SQL→报表→保存→重开；记录阻碍 |
| M1-8 | 安全 | 无网络/无 eval/无 v-html/日志脱敏；只读账号下写操作被拒 |

**止损**：D1（作者不能写/审 SQL）或 D2（拒绝文件式资产）不成立 → 停止，重做立项。

## 发布门（所有里程碑之外）

- [ ] `formatVersion`/插件版本符合 semver；CHANGELOG 说明兼容性。
- [ ] 权限列表最小化；新增权限有说明与用户影响。
- [ ] 文档覆盖：安装、连接授权、保存/重开、截断、错误、隐私、卸载。
- [ ] 已知限制公开：5000 行、无参数、无调度、无共享、AI 可选。
- [ ] 无 P0/P1 缺陷；P2 有规避说明。
- [ ] 许可证/NOTICE/第三方依赖审计完成；商店元数据准确。
- [ ] 支持渠道与响应人明确。
