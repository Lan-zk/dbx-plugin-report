# 发布、签名与安全

> 基线：DBX b160d130；商店流程信息部分未实测（H7）。  
> 发布前必须同时满足 [testing/acceptance.md](../testing/acceptance.md) 的发布门与本文清单。

## 1. 发布形态

- 发行包：`.dbxp`（UI 静态资源 + manifest + 可选 sidecar；本 MVP 无 sidecar）。
- 安装校验：SHA-256 + Ed25519 签名；版本不可变；升级/降级受来源连续性约束。
- 官方商店：`t8y2/dbx-store` 提交 catalog 条目 + 包；官方目录用内置受信公钥验证，不接受自定义密钥。
- 版本：semver；首版 `0.1.0`；manifest `engines.host_api: ^1.4`；`version` 发布后不可覆盖。

## 2. 发布前检查清单

- [ ] 单元/格式/错误映射测试通过；`typecheck`、`build`、`package` 无告警遗留。
- [ ] 真机 V2/V3/V6/V8 按里程碑执行并留证。
- [ ] 权限最小化：`host.workbench`、`host.data:read`、`host.connections:read`、`host.schema:read`、`host.storage`、（可选）`host.ai`；无 `network`/`clipboard`/`filesystem`/`binary` 除非评审通过。
- [ ] manifest id/name/version/description/source/homepage/icon 正确；id 发布后不改。
- [ ] 无凭据、token、测试数据、内部路径进入包；日志/遥测为 0。
- [ ] 第三方依赖清单 + 许可证（SPDX/NOTICE），无 copyleft 冲突；包体积记录。
- [ ] 文档：安装/授权/保存/截断/限制/隐私/卸载；README 与商店描述一致。
- [ ] CSV/图表/JSON 负例通过；无 `v-html`/`unsafe-eval`/远程 URL。
- [ ] 打包产物可安装、可卸载、卸载清理 grants；旧版本不可覆盖。
- [ ] 回滚方案：下架/替换版本、用户卸载说明、已知问题公告。
- [ ] 支持渠道与响应人。

## 3. 商店提交

1. 在 `t8y2/dbx-store` 提 PR：catalog 条目（id/name/version/permissions/source/license 等）。
2. 附包/校验和/签名；人工审核检查权限、描述、来源。
3. 审核通过后目录更新；用户安装时宿主校验。
4. 每次版本升级重复提交；catalog 与 manifest 必须一致。

**未验证（H7）**：审核时长、签名密钥托管、拒绝/申诉流程、权限审查粒度。首次提交前向维护者确认，并把结果回写本文档。

## 4. 威胁模型

### 资产

| 资产 | 位置 | 影响 |
|---|---|---|
| 业务数据（查询结果） | 插件内存/UI/用户导出文件 | 泄漏、越权、误导 |
| SQL 文本 | 文档、内存、日志 | 泄漏业务逻辑/表名 |
| 连接元数据 | 宿主、插件摘要 | 泄漏内部结构 |
| 文档定义 | 本机文件、可能云同步 | 篡改、注入、版本混淆 |
| AI prompt/候选 | 宿主 provider、插件内存 | 数据外发、注入 |
| 插件包/依赖 | 分发链 | 供应链攻击 |

**不持有**：数据库密码/token（宿主管理，插件不请求）。

### 信任边界

```
DBX host（可信）
  → iframe sandbox（不可信：文档/AI/第三方库）
  → 本地文件（不可信输入）
  → AI provider（外部，仅用户 opt-in）
  → 商店/包（供应链）
```

### 威胁与控制

| # | 威胁 | 控制 | 验证 |
|---|---|---|---|
| T1 | 文档/AI 注入脚本/HTML | 严格 JSON schema；Vue 转义；禁 `v-html`；图表配置白名单 | V8 负例 |
| T2 | 通过图表配置外发数据（URL/图片） | 无网络权限；禁止远程 URL；CSP | 抓包/V8 |
| T3 | 绕过只读分类执行写操作 | 只读账号 + 固定 SQL + 不信任前端预检；宿主分类器兜底 | A11/P06 |
| T4 | SQL 注入（未来参数/插槽） | 首版不支持参数；若引入必须 bind API 或严格类型编译+注入测试 | 设计评审 |
| T5 | 截断数据被当完整结果 | `truncated` 强制徽标；禁用全量导出/总计 | A02/A09 |
| T6 | AI 泄露业务行 | 默认不发 rows；只发 schema/词典；用户确认；可关闭 | V4/V8 |
| T7 | 日志/错误泄露敏感值 | 只记 code/耗时/行数；不记 SQL 字面量/结果/连接串 | 代码审计 |
| T8 | CSV 公式注入 | `= + - @` 前置转义；UTF-8/BOM 测试 | V8 |
| T9 | 恶意文档路径/原型污染/解析炸弹 | 5 MiB/深度 64/键白名单/拒 `__proto__` | V6/V8 |
| T10 | 供应链/仿冒包 | 签名/校验和/官方目录/依赖审计 | 发布门 |
| T11 | 权限过度申请 | 最小权限；商店/用户可见；不申请 network | 发布审查 |
| T12 | 多窗口覆盖/静默丢失 | 显式保存、revision 提示、不自动保存 | V6 |

### 安全不变量

- 插件不发起任何网络请求；无 CDN、无遥测、无远程字体/图标。
- 不读取任意文件路径；只处理用户选择的文件/拖入内容。
- 不持有/复制连接凭据；不把连接配置写入文档。
- AI 默认不发送业务行；发送前明确告知；拒绝不影响手工流程。
- 所有用户/AI 字符串按不可信处理；不拼接 HTML/SQL。

## 5. 隐私说明（面向用户）

- 本插件默认完全离线：查询结果只在本机内存/界面；保存仅写用户选择的 JSON 文件。
- 若启用 AI 草稿：会向用户配置的 AI provider 发送**连接类型、字段名/类型、目标描述**；默认不发送结果行；是否发送由用户在每次操作时确认。
- 日志不含 SQL 字面量/结果值；无遥测。
- 卸载插件会删除插件 grants（宿主行为）；用户保存的 JSON 文件不受影响。

## 6. 事件响应与回滚

| 事件 | 动作 |
|---|---|
| 错误结果/假完整 | 立即停止分发该版本；公告限制；修复后重新发版；评估用户影响 |
| 数据外发/越权 | 冻结版本、下架、通知、审计；修复后重新审核 |
| 供应链/签名异常 | 撤销版本、轮换密钥（按商店流程）、通知用户 |
| 文档格式 bug | 提供只读降级/修复工具；保留 `.bak`；不静默迁移 |

**回滚**：商店下架问题版本；用户卸载/装回旧版（宿主版本不可覆盖策略以实际为准）；文档格式保持向后可读。

## 7. 许可与合规

- 依赖许可证审计（SPDX/NOTICE），尤其图表库（ECharts Apache-2.0 候选）与工具链。
- 插件自身许可证待定；商店 `license` 字段只是字符串，不等于合规声明。
- 不使用来源不明/无许可证的代码片段；竞品只借鉴结构，不复制实现。
- 出口/隐私合规按目标市场另行评估（本文不构成法律意见）。
