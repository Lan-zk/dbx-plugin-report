# 决策记录（ADR）与待拍板项

> 状态说明：`暂定`＝分析报告给出的建议，尚未由负责人书面确认；`已定`＝已确认并作为开发约束；`待定`＝会阻塞里程碑。  
> 改动规则：新增/修改决策必须写日期、理由、替代方案与复议条件；影响范围的决策同步更新 [scope.md](scope.md) 和 [roadmap](../development/roadmap.md)。

## ADR-01 SQL 是计算真相，词典不升级成语义编译器

- **状态**：暂定（报告建议）
- **决定**：数据集由一条固定 SQL 定义；指标词典只描述 SQL 输出字段（单位、可加性、时间口径、NULL 策略等），不生成 SQL、不做跨模型 join。
- **理由**：宿主只有单表列元数据和只读单语句执行，没有语义层/关系/指标 API；自建编译器需要一整套建模、正确性和维护预算。
- **替代**：自持完整语义层（延后独立立项）；接外部 dbt/Cube（需真实服务和认证约束）。
- **复议条件**：出现大量“必须自助换维度”的用户，且愿意承担语义层项目成本 → 重新立项，不在本 MVP 内偷偷扩。

## ADR-02 作者工具，不做自助分析

- **状态**：暂定
- **决定**：作者写/审 SQL；读者只操作作者预设的结果过滤、排序、Top N 展示。
- **理由**：宿主不提供关系/指标语义，自助分析需要另一套建模和正确性保证；首版用户被假定能写/审 SQL。
- **替代**：自助拖拽分析（明确不做）。
- **复议条件**：目标用户不能写 SQL，或首版用户演练失败 → 停止当前 MVP，重做立项。

## ADR-03 AI 只出草稿，人工验证与保存

- **状态**：暂定
- **决定**：AI 生成受限 JSON 候选（或 SQL 候选），经 schema/字段/版本/语法检查，作者审阅、`host.queryData` 预览、核对口径后，人工确认保存。AI 不能自动发布、不能自动查询未授权连接。
- **理由**：没有 BI 资产审批/版本事务，模型正确性未证实；自动发布把数据安全和口径风险放到不可控位置。
- **替代**：AI 自动发布/自动建看板（本次否决）；组合 Agent 路径（后续 spike）。
- **复议条件**：V4 达到准确率/人工耗时门槛，且 V5 组合 Agent 验证通过 → 可讨论更自动的流程，但仍需人工确认口径。

## ADR-04 本机 JSON 文件是正式资产

- **状态**：暂定
- **决定**：ProjectDocument JSON 是正式资产；通过宿主 `host.saveFile` 另存；打开需用户选文件/重新绑定连接；`host.storage` 只存偏好和有限草稿，不存业务结果。
- **理由**：UI store 不是资产数据库（256 KiB/值、1 MiB 总量、1024 键、无 CAS/多键事务）；云同步可能搬走草稿；tab/session 不是资产主键。
- **替代**：宿主资产 API/本地服务（需新增 Host API，另立项）。
- **复议条件**：用户拒绝文件式体验且接受新增宿主资产 API 的成本 → 重新裁决。

## ADR-05 技术栈：TypeScript + Vue 3.5 + 自研轻量组件

- **状态**：已定（2026-10-22）
- **决定**：单一 TypeScript 前端包，Vue 3.5 Composition API + `<script setup>`，Vite 8 构建；不引完整 UI 套件、不用 sidecar、不引路由/状态库；图表暂定 ECharts 6 按需，校验 Zod 4，具体版本见 [development/tech-stack.md](../development/tech-stack.md)。
- **理由**：既有架构/安全论证已按 Vue 语义写（`architecture.md` §12、`release-and-security.md` T1），换框架会让论证与实现脱节；`plugin-development.mdx:947` 明确允许 self-managed Vue UI；自研组件避免主题 token 双体系与包体积超标；分层 `ui → core → platform` 使框架替换只需重写 `ui/`。
- **替代**：Svelte 5（官方模板，生态/维护弱，保留为换层备选）；React 19（体积与心智不一致）；UI 套件（Element Plus/Naive UI）。
- **复议条件**：团队维护者变化或 Vue 生态出现阻塞性缺陷 → 只重写 `ui/`，`core/`、`platform/` 不变；图表/校验等单点替换见 tech-stack §8。

## ADR-06 看板布局：12 列网格吸附（2026-10-22 修订：实现引擎改由 ADR-07 决定）

- **状态**：已定（2026-10-22；同日修订）
- **决定（仍有效）**：看板采用 **12 列网格吸附**布局（`layout[]` 为 `{reportId,x,y,w,h}`，单位是格而非像素）；像素级自由画布不做。
- **原决定（已被 ADR-07 取代）**：拖拽/缩放/碰撞/键盘**自研 Pointer Events + CSS Grid**、不引布局引擎、最小卡片 3×4——该结论建立在"≤4 卡"前提上，前提不成立，见 ADR-07。
- **理由（坐标模型仍成立）**：JSON 资产要在不同窗口宽度、别人机器上可移植，像素坐标会随容器宽度失效；网格坐标可静态校验（`x+w≤12`、不重叠、与 `reportRefs` 一致）。
- **替代**：像素级绝对定位（否决：跨宽度不可移植、重叠不可校验）。
- **复议条件**：数据模型改成非网格布局（如分区/行组）→ 重新裁决；仅实现引擎变化不动坐标模型。

## ADR-07 看板规模与布局引擎：单看板 ≤20 卡 + gridstack 14 官方 Vue wrapper

- **状态**：已定（2026-10-22）
- **背景**：ADR-06 原结论"自研拖拽"的前提是"≤4 卡"，该上限来自分析阶段的 MVP 范围假设（`analysis/feasibility-report.md:72,150,246`），不是宿主限制（宿主只限每 bridge 4 个并发查询，`host/limits.md:16`）。真实报表 8–20 卡常见且每卡要能调宽高，故重估。
- **决定**：单看板 `reportRefs` **硬上限 20 张**（UI 建议 ≤12）；坐标模型不变（12 列网格、`{reportId,x,y,w,h}`）；布局引擎改用 **gridstack 14 + 官方 Vue wrapper**（`gridstack/dist/vue`），不再自研拖拽；最小卡片 **2×3 格**。
- **理由**：20 卡时响应式塌缩、碰撞推挤、紧凑排列、嵌套、触屏、键盘入口的边界成本远超自研（估算 1200+ 行）；gridstack 官方 wrapper 用 `<Teleport>` 重挂载，DOM 所有权冲突已由上游解法消除；MIT、零运行时依赖、全量 import 实测 92,459 B min / 25,380 B gzip；`columnOpts` 断点、`mode: compact`、`useWidgetSerializer` 正好对上"多断点 / 紧凑排列 / 额外状态持久化"需求。
- **替代**：grid-layout-plus 1.1.1（Vue 3 原生，但带 interactjs + @vexip-ui 三个依赖、v2 仍是 beta、单维护者）；自研扩容（1200+ 行，不推荐）；像素级自由画布（不做）。
- **代价与风险**：新增 92 KB 级依赖与一个较新的官方 wrapper（v13 起）；需 M0 实测 20 卡首屏/拖拽帧率/主题跟随/打包增量（tech-stack §7 H7–H9）；卡数放宽后刷新预算改为"只刷可见 + 单卡刷 + 全刷"。
- **复议条件**：单看板 >20 卡成为常态，或需要跨看板/嵌套仪表盘 → 重新评估数据模型与引擎（gridstack 支持嵌套子网格，但资产结构要另设计）。

## 待拍板决策（阻塞排期）

| ID | 决策 | 建议默认 | 不接受时的后果 |
|---|---|---|---|
| D1 | 首批目标用户是否能写/审 SQL | 是，定位作者工具 | 若必须业务人员任意探索，当前 MVP 不成立，需语义层项目 |
| D2 | 是否接受本机 JSON、显式另存/重新打开 | 接受，不把 UI store 升级成资产服务器 | 若必须资产库体验，先裁决 sidecar 本地存储或新增宿主资产 API |
| D3 | AI 是否只交草稿、人工预览与保存 | 是，默认不发送业务行 | 若必须 Agent 自动建成，先做 V5 spike；自动发布不可妥协则不建议启动 |
| D4 | 首发数据库与规模 | SQLite/PostgreSQL 认证候选；≤20 卡（建议 ≤12）、手动刷新、5000 返回行 | 增加数据库需增加黄金语料；分页/后台刷新/确认取消须改宿主合同 |
| D5 | 数据与依赖许可政策 | 默认无业务行持久化/外发；按实际依赖做 SPDX/NOTICE 与商店审核 | 禁止任何模型外发则禁 AI；“绝不离机”须另核同步设置 |

**D1–D5 未确认前**：可以做 M0（不影响范围的技术验证），但不得对外承诺 MVP 或排期 M1+。

## 评审已确认的判断（2026-10-22）

以下为分析评审中已认可的判断，仍以 ADR 为准：

5. 首版不新增 Host API；bind/cancel/分页/资产 API 作为宿主路线图输入正式提出，不在插件侧伪装支持。
